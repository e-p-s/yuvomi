## Was ist das Projekt?

Selbstgehostete Haushalts-App (Yuvomi-Fork, Fork von `ulsklyc/yuvomi`, GitHub `e-p-s/yuvomi`).
Kern-Feature Medienzeit: Bildschirmzeit-Kontingente pro Kind mit harter Sperre,
Pflichtzeit, Punkte-Tausch, Einbuchen/Ausbuchen, Geraet-Zuordnung - und seit dem
05.11. die echten Bildschirmzeiten aus Google Family Link, die zu Lasten des
Kontingents gehen. Produktion: LXC CT135 (172.30.95.198:3000, nativer
systemd-Dienst, SQLCipher-DB, Schema v287).

  keinen Chat).
- CT135-DB (SQLCipher): Schluessel in `/opt/yuvomi/.env`; sicherster Weg =
  kurzes .mjs-Snippet, das `server/db.js` ueber dessen eigenen Env-Pfad oeffnet
  (Muster: Fl-inspect vom 05.11.), nicht per Hand-Pragma.
- Push-Token: Klartext liegt ausschliesslich in `~/.familyhub/push_token` auf
  CT122 (0600). Rotation: `POST /familylink/token` (Eltern-Session) -> neue
  Datei + hash wird ersetzt.

## Pitfalls (frisch gelernt, verbindlich)

1. `server/db.js`-Migrationen NIE per `rindex('\n];')` verankern - trifft ein
   weiter unten liegendes Array; Anker = letzte SQL-Zeile der Vor-Migration.
2. OpenAPI-Routen-Tracer (test/openapi-routes.js): ein Router pro Datei, keine
   gemischten Importzeilen (`import X, { Y }`), sonst coverage/reasons rot.
3. `users.family_role` CHECK: nur dad|mom|parent|child|grandparent|relative|other.
4. i18n-Gate verbietet En-/Em-Dashs auch in deutschen Werten -> '-'.
5. Shared-Repo-Regel: explizit `git add <pfad>`, nie `git add -A`.
6. CT135 ist 1 GB LXC: nichts Schweres (Chromium!) auf dem Server-Host starten.

## Wie man weiterarbeitet

1. User loggt Google auf CT122 neu ein (einziger blockierender Schritt).
2. Naechster Cron-Takt (<=5 min) liefert den ersten Report; Pruefung:
   `SELECT google_uid, day, SUM(consumed_min) FROM familylink_daily GROUP BY 1,2;`
   (via db.js-Snippet) und Tageskarte im Browser (nach SW-Neuladen).
3. Bei UI-Korrekturen: Regeln-/Tageskarte-Dateien
   `public/pages/media-time.js` + `public/styles/media-time.css`, dann die
   Test-Suiten aus `package.json` (media-time*, openapi*, i18n*, typography).

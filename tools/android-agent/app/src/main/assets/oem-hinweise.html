Warum diese Seite?

Android-Hersteller beenden Apps im Hintergrund aggressiver als Google es vorsieht. Diese Einstellungen kann keine App selbst setzen - sie muessen einmalig von Hand gesetzt werden. Nach OTA-Updates werden sie gern zurueckgesetzt: wenn der Server "Tracker offline" meldet, hier erneut nachsehen.

Samsung (One UI)

  • Schlafende Apps: Einstellungen → Batterieverbrauch (Geraetepflege) → Hintergrundaktivitaeten → "Schlaffende Apps" → Yuvomi Medienzeit dort nicht eintragen, falls vorhanden → "Nie schlafen" / Ausnahmen hinzufuegen. Hintergrund: Samsung beendet Apps nach ca. 3 Tagen ohne Nutzung im Vordergrund, wenn sie in dieser Liste stehen.
  • Autostart: Einstellungen → Batterieverbrauch → Hintergrundaktivitaeten → "Autostart" → Yuvomi Medienzeit aktivieren.
  • Batterie-Optimierung: auf "Nicht optimiert" stellen (fuehrt der Onboarding-Schritt hin).

Xiaomi / Redmi / POCO (HyperOS / MIUI)

  • Autostart: Einstellungen → Apps → Autostart → Yuvomi Medienzeit erlauben. Ohne Autostart startet der Tracker nach Neustart NICHT (der Boot-Receiver wird von MIUI blockiert).
  • Akku-Sparer: Einstellungen → Akku → Yuvomi Medienzeit → "Keine Einschraenkungen".
  • Hintergrund-Apps sperren: Recently-Apps → Yuvomi-Karte herunterwischen → Schloss-Symbol antippen (geschuetzt vor "Alle schliessen").

Andere Hersteller (Huawei, OPPO, vivo, Realme)

  • Prinzip ueberall gleich: Autostart erlauben + Batterie-"keine Einschraenkung" + App in den Recently-Apps sperren.
  • isbadbatteryapps.com listet die genauen Menuepfade je Modell (externe Referenz).

Was der Tracker ohne diese Einstellungen tut

Er verliert nichts an Daten, die bereits gemessen wurden (der Offline-Puffer bleibt), aber der Upload kann sich verspaeten und der Dienst kann sterben. Der Server zeigt dann "Tracker offline" statt still 0 Minuten - das Kind verliert also keine Punkte durch Hersteller-Eigenheiten. Perfekte Erfassung gibt es ohne Device-Owner/MDM nicht; Yuvomi ist ein Melde-, kein Vollzugssystem.
